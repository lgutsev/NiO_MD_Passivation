# Molecule inputs

LigParGen parameter generation is deliberately outside `nio-md-prep`. Run LigParGen independently, download its LAMMPS `.lmp` output, and save it as `ligpargen.lmp` in the molecule folder. This package never calls LigParGen, BOSS, or infers missing OPLS-AA parameters.

Each folder contains a small `molecule.toml`. `geometry.xyz` is optional and should only be set when a mass cannot identify exactly one element. `overrides.lmp` contains reviewed molecule-specific coefficient commands; it is never generated by inference.
